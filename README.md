# DairyFlow — лабораторная работа №11

Учебный прототип интеллектуальной системы управления ресурсами молочного производства на Next.js и JavaScript.

## Запуск

Требуется Node.js 20.9+.

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

Для production-сборки:

```bash
npm run build
npm start
```

## Реализованные разделы

- **Обзор** — KPI, состояние оборудования, последние измерения и уведомления.
- **Аналитика** — графики электроэнергии, воды и выпуска; описание полей датасета.
- **Модели ML** — базовый прогноз, линейная регрессия, ансамбль деревьев-решений (упрощённый Random Forest), факт/прогноз и метрики MAE, RMSE, R².
- **LSTM** — отдельное обучение LSTM через TensorFlow.js в браузере; временное окно 12 наблюдений, хронологическое разделение и масштабирование по обучающей части.
- **Управление** — сравнение трёх расписаний при одинаковом выпуске.
- **Виртуальный цех** — интерактивная настольная схема резервуара, пастеризатора, охладителя и фасовки.
- **Сценарии** — базовый режим, повышенный спрос, ограничение сырья, простой линии, избыточное потребление и изменение расписания.

## Данные и допущения

Генерируется 5 000 синтетических наблюдений с шагом 5 минут, seed = 42. В данных предусмотрены режимы производства, ожидания и мойки, шум, параметры процесса и три участка искусственного повышения энергопотребления. Данные не являются данными реального предприятия.

Разделение данных: 70% обучение, 15% валидация, 15% тестирование. Для классических моделей используются признаки, известные на момент прогноза. LSTM обучается на последовательностях из 12 наблюдений. Для удобства браузерного обучения число обучающих окон ограничено 1 100.

Сценарные значения планов и состояние виртуального оборудования демонстрационные. Расчётная экономия не доказывает экономию на реальном производстве. Температурные и санитарные ограничения в реальной технологической карте должны задаваться отдельно и не должны ослабляться ради экономии.
